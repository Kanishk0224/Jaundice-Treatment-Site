I am building a REAL production-oriented website and digital platform for a traditional herbal treatment centre in Salem, Tamil Nadu.

PROJECT NAME:
Kuppusamy Goundar Jaundice Treatment Centre

PRIMARY OBJECTIVE:
Build a modern, trustworthy, multilingual and highly mobile-responsive DISCOVER WEBSITE for the herbal centre, together with a PRIVATE ADMIN CMS that allows the centre management to control the content displayed on the public website.

This is NOT supposed to be just a basic college brochure website.

The public website should help people:
- Discover the centre
- Understand who we are
- Learn about our history
- Understand what services/treatment information we provide
- See what the centre looks like
- Understand how to contact and reach us
- View announcements and updates
- Build trust through authentic information, photographs and reviews
- Contact the centre easily
- Eventually support appointment and patient-related functionality

The admin website should allow the centre management to update the public website without modifying source code.

17. SECURITY
==================================================

Treat patient-related functionality as sensitive.

For the Admin CMS:

- Secure authentication
- Role-based authorization
- Supabase Row Level Security
- Secure storage policies
- Validate all inputs
- Sanitize/validate uploaded files
- Do not expose service keys to the browser
- Use environment variables
- Protect admin routes
- Protect API endpoints
- Use secure cookies/session handling
- Avoid exposing database credentials

If patient records are added later:
- Strong access control
- Patient-specific authorization
- Audit logging
- Secure document storage
- Consent/privacy workflow
- Backup strategy
